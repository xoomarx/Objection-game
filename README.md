# Objection! Power Suit

This is a clean static website version of the game.

## Files
- `index.html` — homepage/game page
- `style.css` — game styling
- `game.js` — main game logic
- `improvements.js` — improvements patch loaded after `game.js`

## Vercel setup
Use these settings:

- Framework Preset: Other
- Build Command: leave empty
- Install Command: leave empty
- Output Directory: leave empty
- Root Directory: project root

Do not use Vite, TanStack, Nitro, Lovable, or `dist` for this static version.
